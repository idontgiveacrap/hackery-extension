# DevTools panel icons (Network Rules)

Static assets loaded by path from [`devtools/devtools.js`](../devtools/devtools.js). No runtime drawing.

Source artwork: user-provided black network/globe glyph (transparent background), cropped, recolored, and resized offline.

| File | Color |
|---|---|
| `devtools-icon-default-*.png` | Teal `#81b5a1` — hooks enabled (panel tab) |
| `devtools-icon-disabled-*.png` | Light grey `#d0d6d3` — hooks disabled |
| `devtools-icon-matched-*.png` | Bright green `#4ae09a` — recent match |

Sizes: 16 (tab strip), 32, 48, 96. Toolbar `icon.png` is unchanged.
